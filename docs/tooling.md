# Оснащение: что делает за тебя Claude Code в этом стартере

Методика из `docs/workflow.md` требует независимого ревью, судьи, checkpoint и границ полномочий. В этом стартере всё это не просьба, а механика Claude Code. Здесь описано, что где лежит, когда срабатывает и как выключить. Проверено по официальной документации Claude Code на 2026-10-26; при обновлении Claude Code сверяй форматы.

## Доверие папке

Хуки, разрешения `allow` и импорты из `.claude/settings.json` начинают работать после того, как ты подтвердил доверие папке проекта (Claude Code спрашивает при первом открытии). Запреты (`deny`) и вопросы (`ask`) действуют сразу. Если в начале сессии не пришла ориентировка (дата, ветка, активный план) — доверие ещё не подтверждено или хуки выключены.

## Что где лежит

| Что | Где | Зачем |
|---|---|---|
| Вход | `CLAUDE.md` (Claude), `AGENTS.md` (Codex) | ведут к `docs/workflow.md`, подключают стек и соглашения |
| Правила по темам | `.claude/rules/*.md` | безопасность и git — всегда; тесты и веб — только при работе с такими файлами (`paths:`) |
| Разрешения и хуки | `.claude/settings.json` | что можно без вопросов, что спросить, что нельзя; какие скрипты запускать на событиях |
| Хуки | `scripts/hooks/*.py` | скрипты, которые Claude Code вызывает сам (ниже) |
| Субагенты | `.claude/agents/*.md` | отдельные роли с собственным контекстом |
| Скилы | `.claude/skills/*/SKILL.md` | команды `/имя` и автоматический подхват по описанию |
| Единая проверка | `scripts/check.sh` | тесты, линтер, типы, сборка одной командой |
| Проверка секретов | `scripts/check_secrets.py`, `.github/hooks/pre-commit.sample` | до коммита и в CI |
| CI | `.github/workflows/` | проверка секретов и тестов при push; ревью PR — по включению |

## Хуки — что происходит само

| Событие | Скрипт | Что делает |
|---|---|---|
| Начало сессии | `session_start.py` | подаёт дату и ISO-неделю, ветку и число изменённых файлов, активные планы с последним checkpoint, файл текущей недели, напоминание о калибровке |
| Каждый запрос | `prompt_context.py` | добавляет сегодняшнюю дату и неделю — чтобы даты в планах не придумывались |
| Перед командой в терминале | `guard.py` | **останавливает с объяснением** необратимое: удаление корня/дома/.git, перезапись истории main, чтение файлов с секретами, отправка секретов наружу, запуск скриптов из интернета, права 777. **Спрашивает с объяснением** рискованное: push, удаление веток и изменений, рекурсивное удаление, sudo, публикации и выпуск, команды к базе, отправка данных наружу, установка в систему |
| После правки файла | `format.py` | форматирует код, если в проекте есть форматтер (prettier, ruff/black, gofmt, rustfmt); документацию и `.business/` не трогает |
| Завершение ответа, запрос разрешения | звук | чтобы не сидеть у экрана |

Хук не заменяет правила: в `.claude/rules/security.md` те же требования словами, и Claude обязан им следовать и без хука.

## Разрешения

- **Без вопросов:** чтение, `git status/diff/log/branch/show`, `scripts/check.sh`, проверка секретов, тесты и линтер через npm/pnpm/pytest/ruff, `ls`, `pwd`.
- **Спросить:** `git push`, удаление веток и изменений, `rm`, `sudo`, `curl`/`wget`, публикации (`npm publish`, `gh release`, `gh pr merge`), `docker`, `vercel`, `kubectl`, `terraform`.
- **Нельзя:** чтение `.env*` (кроме `.env.example`/`.env.sample`), ключей и `credentials.json`; `rm -rf` корня, дома, `.git`; `git push --force`; `export … && curl`; `chmod 777`.

Личные дополнения — в `.claude/settings.local.json` (не попадает в git). Режим обхода разрешений стартер не включает и не советует.

## Субагенты — когда их звать

| Агент | Когда | Что возвращает |
|---|---|---|
| `reviewer` | до одобрения плана; после реализации фазы; перед PR | таблица замечаний с доказательствами |
| `judge` | после любого ревью, до правок | решение по каждому замечанию и порядок исправлений |
| `security-auditor` | перед выпуском; формы, авторизация, платежи, внешние API, данные | находки по серьёзности с исправлениями |
| `business-critic` | до одобрения плана; цены, условия, запуск, траты | три стороны: клиент, деньги, риски |
| `researcher` | понять чужой код, страницу, зависимость — до планирования | выжимка с «файл:строка», только чтение |

Порог, чтобы не тратить лишнее: ревью агентами обязательно для планов дольше двух часов работы и для любого изменения, идущего в `main`; мелкие правки — без агентов, но с `scripts/check.sh`. Агенты не правят файлы — правит основная сессия после решений судьи.

## Скилы — команды

| Команда | Что делает |
|---|---|
| `/calibrate` | техническая калибровка: стек, команды проверок, `docs/stack.md` |
| `/spec` | спецификация результата в `specs/` + `business-critic` |
| `/plan` | план в `plans/` + `reviewer` → `judge` → одобрение; или продолжение плана |
| `/review` | независимое ревью текущих изменений или плана |
| `/checkpoint` | записать checkpoint в активный план |
| `/retro` | ретроспектива сессии |
| `/week` | план недели, задачи, итоги, переносы |
| `/stress-test` | стресс-тест решения перед важным шагом |
| `/three-views` | клиент, деньги, риски |
| `/release` | подготовка выпуска: проверки, аудит, CHANGELOG, PR |
| `/decision` | запись в журнал решений |
| `/audit` | аудит существующего кода или системы → `docs/audits/` |
| `/web-audit` | аудит веб-страницы или сайта |
| `/license-audit` | инвентаризация лицензий, сервисов и персональных данных |
| `/post`, `/letter`, `/offer` | тексты для клиентов в голосе владельца |

Промпты в `prompts/` остались для Codex и для тех, кто предпочитает копировать текст.

## Codex

Codex читает `AGENTS.md`, `docs/`, `prompts/` и `.business/`. Хуки, разрешения, субагенты и скилы из `.claude/` — механика Claude Code; Codex их не видит. Скилы в формате `SKILL.md` Codex может использовать, если скопировать нужные папки из `.claude/skills/` в `.agents/skills/` своего проекта — это тот же открытый формат.

## Как выключить

- Один хук — удали его блок из `.claude/settings.json`.
- Все хуки проекта — в настройках Claude Code (`/hooks` или `"disableAllHooks": true` в `settings.local.json`).
- Агент или скил — удали папку/файл.
- Ревью PR на GitHub выключено по умолчанию; включается переменной `CLAUDE_REVIEW=true` и секретом `ANTHROPIC_API_KEY`.

## Стоимость и ограничения

Субагенты и скилы тратят токены как обычные запросы; ориентировка в начале сессии — до 4 000 знаков. Хуки работают локально и бесплатно. Ничто из этого не даёт гарантий: ревью снижает риск, проверка секретов эвристическая, аудит — факты для решения, не заключение.
