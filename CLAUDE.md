# Claude Code: вход в проект

Прочитай [общий процесс](docs/workflow.md) перед работой. Это единый источник правил для Claude Code и Codex; не дублируй его здесь. Оснащение этого стартера — хуки, разрешения, субагенты, скилы — описано в [docs/tooling.md](docs/tooling.md).

Начинай с текущей просьбы и доступного контекста, не с обязательного онбординга. Для продолжения найди действующий план и checkpoint — ориентировку подаёт хук в начале сессии. Локальные договорённости проекта сохраняй; конфликт требований явно обозначай владельцу.

## Как работать здесь

- Работа дольше часа — через `/plan`: план → `reviewer` → `judge` → одобрение владельца. Мелкое — сразу, но с `bash scripts/check.sh`.
- Правила по темам подключаются из `.claude/rules/` сами: безопасность и git — всегда, тесты и веб — при работе с такими файлами.
- Помощник готовит — владелец решает: push, выпуск, платежи, публикации, удаление данных — только после прямого «да» на конкретное действие. Хук спросит, но не полагайся на него.
- Отвечай на языке владельца; по умолчанию русский.
