# Веб-страницы и интерфейс

- Страница должна работать без сторонних скриптов: аналитика, чаты, виджеты подключаются последними и не ломают основное при недоступности.
- Формы: валидация на сервере обязательна, на клиенте — для удобства. Каждая форма с персональными данными знает, куда отправляет данные и зачем; согласие на обработку — там, где этого требуют правила (см. `.business/company/legal.md`).
- Сторонние скрипты, пиксели, cookies — только по решению владельца с записью в `docs/decisions/`: что собирают, кому передают.
- Доступность — базовый минимум: заголовки по порядку, подписи у полей и кнопок, альтернативный текст у картинок, контраст, работа с клавиатуры.
- Производительность: картинки в современных форматах и с размерами, скрипты не блокируют отрисовку, ничего лишнего не грузится на каждой странице.
- В разметке и клиентском коде нет секретов и внутренних адресов. Ключи для браузера — только публичные, с ограничением по домену.
- Любое изменение внешнего вида проверяется на телефоне и на узком экране, не только на большом мониторе.
- Аудит существующих страниц — скил `/web-audit`.
