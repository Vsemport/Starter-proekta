# Codex: вход в проект

Прочитай [общий процесс](docs/workflow.md) перед работой. Это единый источник правил для Codex и Claude Code; не дублируй его здесь. Стек и команды проверок — в `docs/stack.md`, соглашения — в `docs/conventions.md`, решения — в `docs/decisions/`.

Начинай с текущей просьбы и доступного контекста, не с обязательного онбординга. Для продолжения найди действующий план и его checkpoint в `plans/`. Локальные договорённости проекта сохраняй; конфликт требований явно обозначай владельцу.

Хуки, разрешения, субагенты и скилы из `.claude/` — механика Claude Code, Codex их не видит. Поэтому: правила из `.claude/rules/*.md` выполняй сам, как часть этого файла; независимое ревью и судью делай отдельной сессией; перед закрытием фазы — `bash scripts/check.sh`, перед коммитом — `python3 scripts/check_secrets.py --staged`. Скилы `.claude/skills/*/SKILL.md` — открытый формат: нужные можно скопировать в `.agents/skills/` своего проекта.
